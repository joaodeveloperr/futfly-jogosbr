# FutFly - Os jogos acontecem aqui
FutFly e uma plataforma que criei 100% na v0, nela você consegue ver placares e acontecimentos em todos os jogos do brasileirao, copa e etc. Tudo ao vivo em tempo real sem se cadastrar ou pagar.

E um projeto que eu tava no tédio e também queria testar, hoje ele e Open-Source para qualquer um que quer criar um projeto ou plataforma parecida.
